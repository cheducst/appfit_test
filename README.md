# Meu Treino

App local para organizar os treinos importados dos PDFs:

- BÍCEPS + PEITO
- OMBRO E TRÍCEPS
- COSTA E OMBROS

## Como rodar

Abra `index.html` no navegador.

Os dados ficam salvos no armazenamento local do navegador. Nao precisa de backend, conta ou instalacao.

## Principais funcoes

- Cadastrar treinos por nome, grupo e dia.
- Adicionar, editar e excluir exercicios.
- Definir series com repeticoes e carga.
- Marcar series como concluidas durante o treino.
- Finalizar a sessao e salvar historico.
- Ver grafico de dias da semana treinados.
- Ver evolucao de carga por exercicio.
